# 2025-11-30 Initial Planning

## Decisions

- **Service name**: Psykiwi
- **Domain**: psykiwi.com
- **License**: AGPL-3.0 (open source)
- **Target users**: 20-35 year olds interested in self-expression (global)
- **User-facing text**: "Psykiwi" (not "Psy Kiwi")
- **Repo description**: "Describe yourself in 1 link - not 100 words"

## Core Concept

Psykiwi solves: **"How do I explain who I am?"**

- Organize personality/psychology test results in one place
- Share with a single link (psykiwi.com/@username)
- "Want to know who I am? Check this link" — done

### Not a Link-in-Bio Clone

| Linktree                   | Psykiwi                     |
| -------------------------- | --------------------------- |
| Solves platform constraint | Solves self-expression      |
| Link collection            | Psychological business card |

## Why "Psy"?

- Short for "psychology"

## Feature Direction

### Test Result Import

- We don't provide tests ourselves (for now)
- Guide users to external tests (16personalities, truity, etc.)
- Import flow: Screenshot → LLM extraction → Auto-register
- Manual input also available
- Templates for major tests (MBTI, Enneagram, Big Five, etc.)

### Design Direction

- Clean and clear, information delivery first
- References: Linear, Amie, Superlist
